01 / FUNDAMENTOS

¿Qué es una base de datos?

Una base de datos permite almacenar y organizar información para posteriormente consultarla, modificarla o eliminarla.

Su objetivo principal es permitir que los datos puedan ser utilizados de manera estructurada por personas y aplicaciones.

FUNCTION / 01
SAVE

Almacenar

Guardar información de manera organizada para poder utilizarla posteriormente.

FUNCTION / 02
FIND

Consultar

Encontrar rápidamente los datos que necesita una aplicación o una persona.

FUNCTION / 03
EDIT

Modificar

Actualizar información y mantener los datos de acuerdo con el estado actual del sistema.

02 / ARCHITECTURE

SQL
VS
NoSQL

Las bases de datos pueden utilizar diferentes modelos para representar y almacenar información.

Las bases relacionales utilizan tablas y relaciones, mientras que NoSQL engloba diferentes modelos como documentos, clave-valor, columnas y grafos.

RELATIONAL DATABASE

SQL

  • Información organizada en tablas.
  • Esquema definido.
  • Relaciones entre tablas.
  • Alta consistencia e integridad.
  • Consultas mediante SQL.

NON-RELATIONAL DATABASE

NoSQL

  • Documentos, grafos, columnas o clave-valor.
  • Estructura flexible.
  • Diferentes modelos de almacenamiento.
  • Pensado para diferentes necesidades de escala.
  • Puede trabajar con grandes volúmenes.

03 / DECISION

ES NUESTRA ELECCION.

La tecnología debe elegirse de acuerdo con las necesidades del sistema.

Relaciones, estructura, consistencia, volumen de datos y escalabilidad son algunos factores importantes.

NODOS

Una forma diferente de pensar los datos:

¿Qué ocurre cuando lo importante no es solamente la información, sino la conexión entre esa información?

Aquí aparecen los grafos.

Un nodo representa una entidad o elemento. Puede representar una persona, producto, lugar, evento u objeto dentro de un sistema.
Una relación representa la conexión entre diferentes nodos. Por ejemplo: usuario → COMPRA → producto
Porque algunas preguntas dependen más de las conexiones que de los datos individuales. Los grafos permiten representar esas conexiones directamente.
En sistemas de recomendaciones, redes sociales, rutas, relaciones entre personas, análisis de conexiones y otros problemas donde los vínculos son importantes.

Module 01 / Relational Architecture

SQL RELACIONAL

El modelo relacional organiza la información mediante tablas que pueden relacionarse entre sí utilizando claves.

SQL permite consultar y manipular esa información mediante instrucciones estructuradas.

Ejecutar ejemplo Ver conceptos
01 / ANATOMY

Conceptos clave

Una base de datos relacional utiliza tablas, registros, campos y claves para representar información estructurada.

TABLE

Tabla

Estructura formada por filas y columnas donde se almacenan registros.

PK

Llave primaria

Identifica de manera única un registro dentro de una tabla.

FK

Llave foránea

Permite establecer una relación con otra tabla mediante una clave.

02 / RELATION

Relación 1 : N

Un ejemplo sencillo es un alumno que puede tener múltiples calificaciones. La tabla de calificaciones utiliza el identificador del alumno para establecer la relación.

03 / INTERACTIVE

Consulta SQL

Una consulta SQL permite solicitar información específica a una tabla utilizando condiciones. 

SELECT nombre, carrera
FROM alumnos
WHERE carrera = 'Ingeniería';
QUERY STATUS: SUCCESS

01 → Ana López
CARRERA → Ingeniería
04 / ENGINES

Gestores

Existen diferentes sistemas gestores de bases de datos relacionales.

MY

MySQL

Gestor relacional ampliamente utilizado en aplicaciones y sistemas web.

PG

PostgreSQL

Sistema relacional robusto y orientado a aplicaciones avanzadas.

SQ

SQLite

Sistema ligero y embebido utilizado en aplicaciones locales y móviles.

05 / WHEN TO USE

¿Cuándo usar SQL?

El modelo relacional resulta especialmente interesante cuando las relaciones y la consistencia de los datos son importantes.

01

Relaciones

Cuando existen relaciones claras entre diferentes tipos de información.

02

Consistencia

Cuando la integridad y consistencia de los datos son fundamentales.

03

Transacciones

Cuando operaciones como pagos, facturación o movimientos requieren control transaccional.
